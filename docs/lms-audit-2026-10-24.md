# Connect Academy LMS audit — 2026-10-24

## Findings and shipped corrections
1. **Dynamic tab events:** Practice and Library are injected after the LMS initially registers direct click listeners. Switching via those tabs could update DOM visibility without updating the LMS internal active view. LMS now uses a delegated Academy navigation handler, so present and future Learning tabs are handled centrally.
2. **Defensive screen selection:** The previous LMS view switch directly assumed each registered screen existed; all view transitions now check for screen existence before assigning `hidden`.
3. **Session navigation:** Course Catalog/Classroom/My Learning selection now survives ordinary same-tab refresh via sessionStorage, with a safe fallback. Practice and Library are still loaded as dynamically created screens, so a refresh starts on My Learning instead of showing an uninitialized tab.
4. **No focused daily plan:** My Learning now has a short actionable checklist, 10–45 minute target and direct links to Classroom, Practice Lab, Study Library. Daily completion resets at the next calendar day while preserving the chosen goal. The checklist is *self-marked*, not proof of video watching.
5. **Old PWA cache:** Service worker cache version advanced to v82 and current Academy API discovery resources added to its precache. This forces the new worker to replace old cached assets after installation/activation.

## What the repository currently supports
- Local-first course progress and lesson completion, notes, bookmarks and module quizzes
- Course catalog with filters, featured/continued courses and YouTube lesson links
- Dedicated Academy practice studio and Library (dictionary, Gutenberg/Open Library and articles)
- Browser-local practice history, vocabulary recall, reading list and study-plan state

## Remaining limitations
- YouTube lesson completion is **self-reported**, not reliably verified by video playback.
- There is no account-backed sync or teacher-managed gradebook; this is a personal learning portal, not an enterprise LMS.
- External APIs, videos and covers need network access and remain subject to provider availability/CORS/rate limits.
- Legacy CSS/JS compatibility layers still need a separate regression pass and full mobile interaction tests.
- Repo commits are **not** proof that Hostinger deployment or a PWA client is serving the current revision.

## Verification checklist
1. Load /academy, switch My Learning → Course Catalog → Classroom → Practice Lab → Dictionary & Books → My Learning.
2. Refresh on Catalog and confirm Catalog is restored. Refresh on dynamically injected Practice and confirm a working My Learning fallback.
3. Open a course, bookmark lesson, mark a lesson complete, confirm progress update; change course and repeat.
4. On mobile, switch tab labels and confirm just one active screen.
5. Complete study checklist item, refresh and confirm persistence; next day, confirm checklist resets.
6. After service worker update, confirm active PWA uses cache v82.
7. Confirm dictionary / ebook / article provider failures do not break main Academy navigation.

No paid service, login sync or GitHub Actions/deployment alteration is included in this change.
